## 📌 Project Description
MediGuide is a mobile application designed to help users follow medical prescriptions accurately by providing **scheduled medication reminders**, **digital prescription storage**, and **medication history tracking**.


---

## 🧱  Architecture

- **Flask Backend API**
  - User authentication
  - Prescription management
  - Medication history logging
  - Audio transcription service
  - Cloud synchronization

- **MongoDB**
  - Users
  - Medications
  - History records
  - Password reset tokens
